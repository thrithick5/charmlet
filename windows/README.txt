Charmlet - Windows Edition
====================================

Welcome to Charmlet for Windows!

HOW TO INSTALL & RUN:
---------------------
Option 1 (Recommended for Users):
  Download and run "Charmlet-Setup.exe".
  It installs in seconds without requiring admin privileges, creates
  Desktop and Start Menu shortcuts with the official charm icon, and
  launches Charmlet automatically.

Option 2 (Standalone Executable):
  Run "Charmlet.exe" directly. It launches Charmlet in a dedicated
  standalone app window without any console or command prompts.

Option 3 (Portable / Scripts):
  Double-click "Launch.vbs" (silent launch) or "run.bat".

Option 4 (In Any Browser / PWA):
  Open "web\charm.html" directly in Microsoft Edge or Google Chrome.
  Click the App icon in the address bar -> "Install Charmlet" to pin
  it directly to your Windows Taskbar and Start Menu.

FEATURES:
---------
- 20 interactive talismans & charms from world traditions
- Real Verlet rope and bead physics
- Idle wind sway, cursor interaction, and ritual animations
- 100% offline, private, zero data collection, no account needed.

Enjoy!
