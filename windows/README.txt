Charmlet - Windows Edition
====================================

Welcome to Charmlet for Windows!

Charmlet on Windows is a native transparent desktop overlay application that works
identically to the macOS version:
- 100% transparent: floats directly on your desktop over open windows & wallpaper
- Click-through: you can click right through the window to interact with all your apps
- Interactive: moving your cursor over the charm highlights it; click and drag to pull, swing, and flick
- System Tray: right-click the green Charmlet icon in your Windows Taskbar corner (near the clock) to change charms, adjust rope length/size/position, mute sound, or toggle auto-start
- Keyboard Shortcuts:
    Ctrl + Shift + D : Show / Hide Charm
    Ctrl + Shift + S : Perform Ritual
    Ctrl + Shift + F : Flick It

HOW TO RUN:
-----------
Option 1 (Recommended):
  Download and run "Charmlet-Setup.exe".
  It installs in seconds without requiring admin privileges, creates
  Desktop and Start Menu shortcuts with the official charm icon, and
  launches Charmlet automatically.

Option 2 (Portable Standalone):
  Extract "Charmlet-Windows.zip", open the "Charmlet-win32-x64" folder,
  and double-click "Charmlet.exe" directly. No installation required.

NOTE ON WINDOWS DEFENDER / SMARTSCREEN:
--------------------------------------
Because Charmlet is a free, newly compiled personal application without a $400/yr
commercial EV certificate, Windows SmartScreen may show "Windows protected your PC".
To open:
  1. Click "More info"
  2. Click "Run anyway"

Enjoy your good luck!
